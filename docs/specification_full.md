# FiRec 開発仕様書

## 1. 文書の目的

本仕様書は、TIFF 画像から放射線照射野と光照射野を解析し、結果を記録・出力する FiRec を、現在の機能を基準に新規開発するための仕様書である。

実装担当者は、本書に記載された利用者の操作、画面の状態、計算結果、保存結果を満たすことを目標とする。

## 2. 背景と目的

フィルム画像上の放射線照射野と、光照射野の位置・大きさを比較したい。画像処理で初期値を求めつつ、最終的な判断は利用者が画像と補助表示を確認して行えるようにする。

目的は次の通り。

- TIFF 画像を読み込む
- 画像上で解析対象を確認・調整する
- radiation field と light field の形状・位置を比較する
- pixel または mm 単位で結果を確認する
- 解析結果を保存し、過去データを一覧・CSVで扱う

## 3. 対象利用者

- 放射線照射野の確認を行う担当者
- 画像処理やプログラミングの専門知識を持たない利用者
- 保存済みの解析結果を確認・出力する担当者

利用者はコードを編集せず、画面上の画像、矩形、数値、プロファイルを確認しながら操作する。

## 4. 用語

- **radiation field**: フィルム上で黒くなった放射線照射野。
- **light field**: 光照射野の境界を表す矩形。
- **レーザー中心**: 解析時の基準点。
- **プロファイル**: 画像上の線に沿った画素値の変化。
- **origin**: 結果を表示する際の基準点。レーザー、radiation、light から選択する。

## 5. 対応環境と入出力

### 5.1 入力

- TIFF / TIF 画像
- 必要に応じて手動で指定する DPI

画像はグレースケールとして扱う。カラー TIFF は解析前にグレースケール化する。

### 5.2 出力

- 画面上の解析結果
- SQLite に保存する解析記録
- CSV ファイル
- Windows で単独起動できる実行形式

### 5.3 単位

- DPI が利用できない場合は pixel 単位で表示する。
- TIFF メタデータに DPI がある場合は、その値を使用できる。
- 利用者が手動 DPI を選択した場合は、その値で mm に換算する。
- 換算は `mm = pixel × 25.4 / DPI` とする。

## 6. 画面構成

アプリケーションは次の2タブで構成する。

### 6.1 Analyse

解析を行う画面。左側に画像、右側に操作 UI を表示する。右側は縦方向にスクロールできる。

右側には次のフレームを上から配置する。

1. Load
2. Laser center
3. Radiation
4. Light
5. Result
6. 表示設定・補助操作

画像下部には、選択中の矩形を操作する Operation UI を配置する。

### 6.2 Records

保存済み結果を表示する画面。画像表示は行わず、表を主領域とする。

必要な操作:

- 保存結果の一覧表示
- 表示列の選択
- origin の変更
- DPI の変更
- 選択行の削除
- CSV 出力

## 7. 解析ワークフロー

### 7.1 Load

1. 利用者が TIFF のパスを入力するか、ファイル選択画面から選ぶ。
2. `Open TIFF` を押す。
3. 画像を表示する。
4. 画像名、データ型、画素値の範囲を表示する。
5. DPI をメタデータまたは手動指定から決定する。

画像読み込み前は、解析画像や矩形を表示しない。読み込みに失敗した場合は、原因を利用者に伝え、現在の解析状態を壊さない。

完了条件:

- 対象画像が表示されている。
- 画像名と基本情報が確認できる。
- 次のステップを選択できる。

### 7.2 Laser center

1. 画像読み込み後、レーザー中心の初期値を設定する。
2. 利用者が画像上で中心位置を確認する。
3. 必要に応じて中心を移動する。
4. `Set laser center` で確定する。

中心点は画像上で識別しやすい色で表示する。中心位置を変更した場合、中心を基準に配置されるプロファイルや結果表示を更新する。

完了条件:

- レーザー中心が画像上に表示されている。
- 利用者が位置を確認して確定している。

### 7.3 Radiation

放射線照射野の境界を決定する。

#### 初期値

- 大津の方法などで初期閾値を算出する。
- 暗い領域から radiation の初期矩形または初期境界を求める。
- 自動推定が不十分でも処理を停止せず、利用者が調整できる状態を表示する。

#### プロファイル

- 画像の上下左右にプロファイルを表示する。
- プロファイル線を自動配置または手動配置する。
- raw と smoothing 後のプロファイルを切り替えられる。
- プロファイル上の境界カーソルを移動できる。
- プロファイルの境界位置を画像上の radiation 境界へ反映する。

#### 設定値

- 未照射フィルム側の基準画素値
- 閾値または閾値割合
- 中心付近の平均範囲
- smoothing 幅
- プロファイル配置方法
- レーザー中心からのオフセット

#### 操作

- 矩形または境界をドラッグして調整する。
- 矢印キーで細かく移動する。
- 上下左右の移動、回転、拡大縮小を操作できる。
- 選択中の辺は識別できるように表示する。
- 点線の矩形、中心、頂点、辺長、面積を表示できる。

`Set radiation` を押すと radiation を確定する。確定前の light 矩形は表示しない。

完了条件:

- radiation の境界・矩形が画像上で確認できる。
- 利用者が閾値や境界を調整できる。
- radiation を確定できる。

### 7.4 Light

Radiation 確定後、radiation と同じ角度・初期寸法の矩形を light の初期値として表示する。

操作:

- radiation の表示・非表示を切り替える。
- light の上・下・左・右の辺を選択する。
- 選択した辺をドラッグまたは矢印キーで移動する。
- 矩形全体を上下左右に移動する。
- 必要に応じて回転・拡大縮小する。
- `Reset light` で radiation と同じ初期状態へ戻す。

画像表示には次の操作を持たせる。

- マウスホイールで拡大縮小
- 矩形の辺以外をドラッグしてパン
- ダブルクリックで拡大率と表示位置をリセット

`Set light` を押すと light を確定する。

完了条件:

- light の四辺が画像上で確認できる。
- radiation との位置・大きさの関係を確認できる。
- light を確定できる。

### 7.5 Result

結果画面には今回の解析結果だけを表示する。表示項目には次を含める。

- 画像名
- 解析日時
- 使用単位
- origin
- radiation の中心
- light の中心
- radiation の各辺長
- light の各辺長
- radiation の面積
- light の面積
- 辺長の比率
- 面積の比率
- 中心位置の差
- 頂点座標

利用者が画像と結果を確認した後、`Save` で保存する。

## 8. 画像表示と操作ツール

基本ツール:

- パン
- ズーム
- リセット
- 円形 ROI の平均値測定
- 矩形 ROI の平均値測定
- 2点間の距離測定

表示切替:

- レーザー中心
- radiation の境界、中心、面積、辺長、頂点、境界点
- light の境界、中心、辺長、頂点
- プロファイル線
- 点ラベル

表示設定は線幅、点の大きさ、透明度、点線間隔を変更できる。変更結果は即時に画像へ反映する。

## 9. 操作状態と制約

- 現在選択中の解析フレームを明示する。
- 現在のステップに関係しない編集操作は無効化する。
- Tab / Shift+Tab で解析フレーム間を移動できる。
- 上下ボタンでもステップを移動できる。
- Load 前は radiation、light、result の編集をできない。
- Radiation 確定前は light を編集できない。
- Light 確定前は結果保存できない。
- load、radiation、light の完了状態をフレームのマークで示す。
- 前のステップへ戻った場合、後続ステップの確定状態を解除する。

## 10. 記録仕様

### 10.1 保存項目

- ID
- 解析日時
- 画像ファイル名
- origin
- DPI
- 単位
- レーザー中心座標
- radiation 中心座標
- light 中心座標
- radiation の横幅・縦幅・面積
- light の横幅・縦幅・面積

### 10.2 Records

- 日時順に一覧表示する。
- 表示列を選択できる。
- origin と DPI を記録単位で変更できる。
- 選択した記録を削除できる。
- 現在の一覧を CSV に出力できる。

## 11. エラー・例外時の扱い

- TIFF を読み込めない場合は、ファイル形式・パス・破損の可能性を示す。
- 自動検出に失敗しても、可能なら調整可能な初期状態を表示する。
- 必要な境界が設定されていない場合は、次のステップや保存へ進めない。
- DPI がない場合は pixel 単位で継続できる。
- 保存に失敗した場合は、結果を失わず、再保存できる状態を維持する。
- 解析中の未保存データを、別画像の読み込みで意図せず上書きしない。

## 12. 受け入れ条件

- TIFF を読み込み、画像を表示できる。
- 画像読み込み前に解析用矩形が表示されない。
- radiation を自動初期化し、利用者が閾値・境界・矩形を調整できる。
- radiation 確定後にのみ light の初期矩形が表示される。
- light の角度が radiation と一致する。
- radiation と light の中心、辺長、面積、比率を表示できる。
- DPI がある場合は mm を表示でき、ない場合は pixel で表示できる。
- 結果を SQLite に保存し、Records で確認できる。
- Records を CSV に出力できる。
- 解析操作をテスト用画像で再現できる。
- Windows 用の配布形態で起動・画像読み込み・保存ができる。
