# 開発開始時点の初期仕様書

## 1. 文書の位置付け

この文書は、Git の最初の主要コミットである「解析コア機能大体完成」より前、特にユーザー指示「04. 照射野の自動取得と矩形調整」付近で、どこまで仕様が固まっていたかを整理したものである。

後から追加された画面レイアウト、ステップ制御、表示オプション、記録画面などは、当初仕様とは分けて記載する。

厳密な日付や当時の設計書は残っていないため、内容は会話上の指示とプロジェクト目標から、おおよその初期仕様として整理している。

## 2. 目的

TIFF 画像上の放射線照射野と光照射野を矩形として設定し、両者を比較する解析ソフトを作成する。

最終的には、画像を確認しながらユーザーが矩形を調整し、照射野の大きさや位置の差を確認できるようにする。

## 3. 用語

### 3.1 radiation field

フィルム上で黒くなっている領域。画像処理により、おおよその矩形を自動取得する対象。

### 3.2 light field

照射時に境界へ付けた点、または境界位置をもとに作成する光照射野。radiation field を初期状態の基準として、ユーザーが調整する対象。

## 4. 開発開始時点で確定していた要求

### 4.1 画像入力

- 入力画像は TIFF を対象とする。
- 画像を GUI 上で表示する。
- 画像と矩形を見比べながら作業できるようにする。

### 4.2 radiation field の自動取得

- radiation field は OpenCV を用いて自動取得する。
- 最初の二値化には大津の方法を使用する。
- 大津の方法で得た閾値を基準に、暗い領域から radiation field の矩形を求める。
- 大津の方法でうまくいかない場合は、閾値を手動で変更して再度二値化できるようにする。
- 自動取得の精度は、最初から完全である必要はない。
- 自動取得結果は最終結果ではなく、ユーザーが調整するための仮の矩形とする。

### 4.3 閾値の扱い

- 大津の方法で算出した閾値を確認できるようにする。
- ユーザーが閾値を上下させられるようにする。
- 閾値を変更した結果、取得される矩形がどう変わるか確認できるようにする。

### 4.4 radiation field の手動調整

- 自動取得した仮の矩形を、ユーザーが画像上で調整する。
- 矩形は回転可能とする。
- 矩形を上下左右へ移動できるようにする。
- 矩形を拡大・縮小できるようにする。
- 矩形の辺または点を対象として細かく調整する案が出ていた。
- 調整操作には、画像上のクリックと矢印キーを使用する。

この時点では、辺や点の具体的な選択方法、キーボード操作の組み合わせ、1回の移動量までは確定していなかった。

### 4.5 light field の設定

- light field は radiation field と同じ角度の矩形とする。
- radiation field が確定した後、その矩形を light field の初期状態として表示する。
- light field の各辺を個別に調整できるようにする。
- 調整には画像上のクリック、ドラッグ、矢印キーを使用する方向で検討していた。
- radiation field と light field を画像上で確認してから解析結果を確定する。

### 4.6 幾何計算

矩形を構成する点から、少なくとも次の値を計算する。

- 各辺の長さ
- radiation field と light field の大きさの比率
- radiation field の中心位置
- light field の中心位置
- 2つの中心位置の差

矩形は回転を許可するため、中心は矩形の対角線の交点から求める方針とした。

### 4.7 結果の単位

- 最初は pixel 単位でよい。
- TIFF のメタデータが利用できる場合は、mm 単位への換算も可能とする。
- メタデータがない画像でも、pixel 単位で解析できるようにする。

### 4.8 保存・利用環境に関するプロジェクト前提

プロジェクト全体の前提として、次の方向性も置かれていた。

- Python と関連ライブラリで開発する。
- 最終的には Windows 用のスタンドアロン実行ファイルを目指す。
- 解析結果は SQLite に記録する。
- 記録は解析日時順に扱い、CSV として出力できるようにする。

ただし、この時点では、保存する列の詳細、検索条件、画面構成、CSV の列形式までは確定していなかった。

## 5. 想定していた初期処理フロー

```text
TIFF画像を読み込む
        ↓
大津の方法で閾値を求める
        ↓
二値化して radiation field の仮矩形を取得
        ↓
必要なら閾値を手動変更して再取得
        ↓
ユーザーが radiation field を移動・回転・拡大縮小して確定
        ↓
radiation field と同じ角度の light field を作成
        ↓
ユーザーが light field の各辺を調整
        ↓
矩形の辺長・比率・中心位置の差を計算
        ↓
結果を表示・保存
```

この段階では、現在の `Analyse` / `Records` の2タブ構成や、load / radiation / light / result のフレーム構成はまだ決まっていなかった。

## 8. この状態で開発を開始できた理由

細部は未確定だったが、コア実装を開始するには十分な仕様がそろっていた。

- 何を入力するかが決まっていた
- 何を自動化するかが決まっていた
- 自動結果を最終結果にしない方針が決まっていた
- どの形状を扱うかが決まっていた
- 何を計算するかが決まっていた
- pixel と mm の扱いの優先順位が決まっていた

一方、GUI の細かな操作や保存画面は、コア計算を実装しながら具体化しても大きな問題がない部分だった。そのため、まず解析コアから開発を始め、後の会話で GUI 操作や表示方法を詳細化する流れになった。
