# FiRec 会話ベース開発まとめ

## 時系列

1. 初期要求
   radiation/light領域のリセット、回転ボタン表記変更、二値化後の矩形復元など、既存GUI操作の改善。

2. ラインプロファイル導入
   照射野の縦横ラインプロファイルを画像ビューの周囲に表示し、線をドラッグ・矢印キーで移動できるようにしたい、という要求へ変化。

3. 解析仕様の大幅変更
   大津法・二値化・矩形自動判定を中心にした流れから、ラインプロファイル上で `L1/R1/L2/R2/U1/D1/U2/D2` を指定し、4本の直線で囲まれる照射野を定義する方式へ変更。

4. GUI操作の整理
   Load、Radiation、Light、ResultのステップUIを見直し、Loadは解析ステップ外へ移動。画像選択、ラインプロファイル、ステップ操作、表示オプションを整理。

5. 表示と説明可能性の改善
   radiation/lightの辺、領域、中心、set pointを表示切替可能にし、Resultに頂点座標、中心点、辺長、面積を表示する要求へ発展。

## 使用決定ログ

- `PySide6`
  GUI本体に採用。既存コードで `QMainWindow`, `QGraphicsView`, `QGroupBox`, `QTreeWidget` などを使用しており、画像ビューと操作UIの構築に使われている。

- `numpy`
  画像配列、ラインプロファイル、幾何計算の基礎に使用。

- `opencv-python-headless`
  画像処理、矩形・輪郭処理、回転処理などに使用。会話途中で自動判定は主役ではなくなったが、コード上は一部機能が残っている。

- `tifffile`
  TIFF画像の読み込み、DPIメタデータ取得に使用。

- `pyqtgraph`
  requirements上で確認。プロファイル表示などの用途と推定。ただし現在の `ProfilePlot` は独自 `QWidget` 描画。

- `pytest`, `pytest-qt`
  GUIを含む動作検証に使用。確認時点で `41 passed`。

- `PyInstaller`
  実行ファイル化のためrequirementsに含まれる。エントリは `src/firec/gui/app.py`。

動作確認・テスト済み:

実運用に残っている課題:

- GUIの見た目、色、フレーム階層は試用しながら調整が必要。

- PyInstallerで実行ファイル化した後の実機確認は未確認。
- 医療・品質管理用途で使うなら、既知画像を用いた解析精度検証が必要。
- 自動検出系の残存機能と手動指定ワークフローの責務整理が必要。

## 残課題

- 「完成機能」として扱う範囲の整理
  会話では大津法や自動矩形判定を外す方向だったが、コード上にはプロファイル境界自動検出や旧処理由来の関数が残っている。残すか削るかを決める必要がある。

- light領域モデルの統一
  radiationは4点ポリゴン、lightも表示上はポリゴンだが、保存・比較では `RotatedRect` 由来の値も使われる箇所がある。実運用前にデータモデルを統一するべき。

- UI検証
  自然言語で素早くGUIを作り込めた一方、色、配置、選択状態の分かりやすさは実際に触って調整する必要があった。

- 実行ファイル化
  `PyInstaller` は導入済みだが、配布用ビルド、画像読み込み、DB保存、Qt依存関係の確認は別途必要。

## 発表で使う要点

- 非エンジニアでも、コードを書かずに自然言語で「解析の流れ」「見たい表示」「操作しにくい点」を伝えることで、GUI解析ソフトを段階的に完成へ近づけられた。

- 要求は固定ではなく、試用しながら変化した。
  最初は自動二値化・矩形検出だったが、最終的にはラインプロファイルを見ながら点を指定し、説明可能な照射野定義を行う方式に変わった。

- 重要だった判断は「自動化」より「確認可能性」。
  ラインプロファイル、set point、頂点座標、中心、辺長、面積を表示することで、なぜその結果になったかを確認しやすくした。

- ただし検証は必須。
  自然言語で実装は進められるが、UIの分かりやすさ、解析値の妥当性、保存値、実行ファイル化後の動作はテストと実機確認が必要。

発表用の4段階に圧縮すると、以下の流れ。

1. 解析基盤
   TIFF読み込み、画像処理、幾何計算、照射野・光照射野比較。

2. 画像を見ながら調整するGUI
   ラインプロファイル、set point、radiation/light領域編集、表示オプション。

3. 記録と単位変換
   結果保存、Record表示、CSV出力、DPIによるmm換算。

4. 利用性・説明可能性の向上
   ステップUI、表示色の整理、Result詳細表示、中心点・辺長・面積の可視化。
