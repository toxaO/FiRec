# FiRec 再開発仕様書（主要業務フロー版）

## 1. 目的

TIFF 画像から radiation field と light field を比較し、照射野の大きさと位置の差を記録する。利用者は自動推定を確認・修正してから結果を保存する。

## 2. 利用者が行う作業

```text
画像を開く
  ↓
レーザー中心を確認する
  ↓
radiation field を設定する
  ↓
light field を設定する
  ↓
結果を確認する
  ↓
保存・過去記録の出力
```

## 3. 画面

- `Analyse`: 現在の画像を見ながら解析する。
- `Records`: 過去の結果を表で確認・出力する。

Analyse は左に画像、右に操作欄を配置する。現在のステップに不要な操作は無効にする。

## 4. 解析手順

### 4.1 画像を開く

利用者は TIFF ファイルを選択して読み込む。読み込み後、画像名と画像情報を表示する。画像が開けない場合は解析を開始しない。

完了条件: 対象画像が画面に表示される。

### 4.2 レーザー中心を確認する

画像上にレーザー中心を表示する。利用者は必要に応じて中心を移動し、確定する。中心は radiation と light の位置比較の基準として使用する。

完了条件: 利用者が中心位置を確認して確定する。

### 4.3 radiation field を設定する

画像処理で仮の境界または矩形を作る。初期値には大津の方法などを使用する。推定が不正確でもエラーで処理を終了せず、利用者が修正できる状態を表示する。

利用者は次を確認・調整する。

- 画像上の radiation の位置
- 矩形の大きさ
- 矩形の角度
- 閾値
- プロファイル上の境界位置

画像の上下左右にプロファイルを表示し、境界位置を確認できる。矩形の移動、回転、拡大縮小、辺の微調整をマウスとキーボードで行う。

完了条件: radiation の矩形が画像と一致すると利用者が判断し、確定する。

### 4.4 light field を設定する

radiation を確定した後、同じ角度の矩形を light の初期値として表示する。radiation 確定前には light の矩形を表示しない。

利用者は light の上・下・左・右の辺を調整する。radiation を表示したまま重なりを比較でき、必要に応じて表示を切り替えられる。

完了条件: light の矩形を確認し、確定する。

### 4.5 結果を確認する

今回の解析結果として、次を表示する。

- 画像名と解析日時
- radiation / light の中心
- 各辺の長さ
- 面積
- 長さ・面積の比率
- 中心位置の差
- 使用単位

DPI が利用できる場合は mm、利用できない場合は pixel を使用する。

完了条件: 利用者が画像上の矩形と数値結果を確認する。

### 4.6 保存する

確認済みの結果を SQLite に保存する。保存後は Records で表示できる。保存前に必要な矩形が確定していない場合は保存できない。

## 5. Records の操作

Records では画像ではなく表を主に表示する。

- 保存済み結果を日時順に見る。
- 必要な列だけを表示する。
- origin や DPI を修正する。
- 不要な記録を削除する。
- 一覧を CSV に出力する。

## 6. 必須の利用者向け制約

- 画像を開くまで解析を開始できない。
- radiation を確定するまで light を設定できない。
- light を確定するまで結果を保存できない。
- 自動推定の結果を利用者が確認・修正できる。
- 画像と矩形を同時に確認できる。
- 自動推定に失敗しても、手動調整の余地を残す。

## 7. 最低限の完成判定

次の一連の操作を完了できれば、主要業務フローの初版完成とする。

1. テスト用 TIFF を開く。
2. レーザー中心を確認する。
3. radiation を仮設定し、利用者が矩形を修正する。
4. radiation と同じ角度の light を表示する。
5. light の各辺を修正する。
6. pixel または mm の結果を表示する。
7. 結果を保存する。
8. Records で保存結果を確認する。
9. CSV を出力する。
