# FiRec 最初期 GUI レイアウト復元

## 位置付け

これは、Git 最初の主要コミット `e0eb051`（2026-06-15）の GUI 実装と、開発初期の会話内容をもとにした発表用の簡略復元図である。

当時のスクリーンショットそのものではないため、正確な色・余白・フォントは再現していない。画面の構成要素と配置を説明するための資料として使用する。

## 配置の根拠

### 1. 上部: 画像パス入力

画像表示領域の上に TIFF 画像のパス入力欄を置き、右端に `Browse` ボタンを配置していた。

```text
[ TIFF image path                                      ] [Browse]
```

画像を読み込むと、画像表示とプロファイル表示が更新される構成だった。

### 2. 中央左: 画像と4方向のプロファイル

画像を中央に配置し、上下左右にラインプロファイルを置いていた。

- 上: 上辺方向の画素値プロファイル
- 下: 下辺方向の画素値プロファイル
- 左: 左辺方向の画素値プロファイル
- 右: 右辺方向の画素値プロファイル
- 中央: TIFF 画像と照射野・光照射野の表示

つまり、画像単体ではなく、画像の周囲に境界確認用のグラフを配置する設計だった。

初期 GUI の重要な特徴は、radiation の境界を画像だけで判断せず、4本のプロファイルを見ながら点を設定する点である。

### 3. 右側: 縦並びの解析ステップ

右側には、解析の順番に沿って次の枠を縦に配置していた。

```text
Radiation
  Set points on four profiles.

Light
  Reset

Result
  結果表示欄
  Save
```

radiation では4本のプロファイル上に点を設定し、light では radiation を基準にした矩形を調整し、result で結果を表示・保存する流れだった。

### 4. 右側下部: ステップ移動と表示オプション

解析ステップを移動する `previous` / `next` ボタンと、画像上の表示要素を切り替える `Options` を右側下部に配置していた。

この時点では、現在のような load フレーム、完了マーク、詳細な operation ボタン、スクロール可能な操作パネルはまだ整理されていなかった。

## 初期実装時点の状態

Git 初回コミットのコードから確認できる主な状態は次の通り。

- ウィンドウ初期サイズは約 `900 x 680`
- メインタブは `Analyse` と `Record`
- 画像は左側、操作パネルは右側
- 右側の操作パネルは `Radiation`、`Light`、`Result`、`Options`
- 画像の上下左右にプロファイルグラフを配置
- Radiation は4本のプロファイル上の点設定を中心にした UI
- Light には `Reset` ボタン
- Result には結果表示欄と `Save` ボタン
- Record タブには保存済み結果の表、`Export CSV`、`Refresh`
- 画像未読み込み時の初期ステップは radiation

## 発表用の説明

### 30秒版

「最初期の画面は、画像を中央に置き、その上下左右に画素値のプロファイルを表示する構成でした。右側には Radiation、Light、Result の操作欄を縦に並べ、画像とグラフを見ながら照射野の境界を設定し、光照射野を調整して、最後に結果を保存する流れを作っていました。」

### 開発の意味を含めた説明

「最初から見栄えの整った業務画面を作ったのではなく、まず解析に必要な情報を一画面に集めました。画像の周囲にプロファイルを置いたのは、矩形の境界がどの画素値で決まったのかを確認できるようにするためです。その後、実際に操作してみて、load、radiation、light、result の役割分担や、ステップを誤操作しないための UI を段階的に整理しました。」

## 現在の GUI との違い

| 項目 | 最初期 | 後の整理後 |
|---|---|---|
| 画像領域 | 中央、周囲に4プロファイル | 左側の画像領域を中心に整理 |
| 操作領域 | Radiation / Light / Result / Options | load / radiation / light / result のフレーム |
| 解析ステップ | 簡単な previous / next | フレーム選択、無効化、完了マーク |
| radiation | 4本のプロファイル上の点設定 | 自動・手動設定、閾値、詳細調整 |
| light | Reset と矩形編集 | radiation 表示切替、辺調整、操作ボタン |
| 画像操作 | 基本的な画像・矩形操作 | ズーム、パン、リセット、表示オプション |
| 表示 | 基本的な矩形・中心・面積 | 要素別の表示切替、ラベル、線幅など |
| サイズ | 約 900 x 680 | 約 800 x 600 を目標に調整 |

## 再現時の注意

この図は、初期実装をそのまま復元したスクリーンショットではなく、コード上のレイアウトを発表向けに抽象化したものである。発表では「初期画面の正確な画面写真」ではなく、「最初期にどの情報を一画面へ集め、そこからどう整理したか」を説明する図として扱うのが適切である。
